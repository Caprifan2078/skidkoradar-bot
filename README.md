# СкидкоРадар — Telegram-бот поиска скидок

Частный репозиторий проекта. **Бот пока не запущен, реальные остатки торговых сетей ещё не подключены.**

## Как перенести проверенный проект v0.9 с телефона

1. В чате ChatGPT скачай файл `skidki_telegram_bot_v09_catalog_scan.zip`.
2. Открой этот репозиторий в Chrome, при необходимости включи **Версия для ПК**.
3. Нажми **Add file → Upload files**, выбери **ZIP целиком** и нажми **Commit changes**.
4. В разделе **Actions** должен запуститься workflow **Import SkidkoRadar v0.9**. Он сверяет SHA-256 архива, безопасно распаковывает файлы, выполняет тесты и сохраняет проверенный исходный код в репозитории. Если workflow не запустился, открой его вручную через **Run workflow**.
5. В итоге в корне появятся `bot.py`, `core.py`, `providers.py`, `tests/` и другие файлы.

**Не загружай в GitHub токен BotFather**, файл `.env`, пароли или другие секреты. Позже токен зададим через секретные переменные сервиса хостинга.

Последняя локальная проверка архива перед импортом: **67 тестов пройдены**. Проверки реальных цен и остатков по магазинам не выполнены. Наличие исходников не означает, что бот уже работает 24/7.

## План

- Проверить реальные источники цен и наличия, начиная с одной торговой сети.
- Сопоставлять цену, остаток, адрес магазина и время проверки; не выдавать неизвестные остатки за подтверждённые.
- Мониторить скидочные Telegram-каналы параллельно с независимым сканированием каталогов.
- Затем развернуть на облачном сервере без ПК.
